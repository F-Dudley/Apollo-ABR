
**Network Traces**

Provides Cooked Network Traces from real-world network conditions, including both Ethernet and LTE environments. These traces are used to simulate network conditions for testing ABR policies.

Taken from the following sources:
- [MERINA Traces](https://github.com/confiwent/Real-world-bandwidth-traces/tree/master)
  Using Cooked TCC ORI, and Puffer datasets, which are all available in the above repository. These datasets contain bandwidth traces collected from real-world network conditions, including both Ethernet and LTE environments. The traces are used to simulate network conditions for testing ABR policies. (Used within MERINA, and Pensieve)
- [UCC Traces 4G](https://www.ucc.ie/en/misl/research/datasets/ivid_4g_lte_dataset/) & [UCC Traces 5G](https://github.com/uccmisl/5Gdataset)
  Provides Network Traces in combination to Signal Strength, and other network specifics.
